# Personal AI Data Analyst

An AI-powered data analysis platform that automatically generates dataset insights, visualizations, and anomaly detection results.

## Features

- Automated Exploratory Data Analysis (EDA)
- Context-aware analysis suggestions
- Anomaly Detection using Z-Score
- Interactive visualizations
- Support for CSV, Excel, and JSON files
- Optional LLM-powered custom analysis using Ollama

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- SciPy
- DuckDB
- Ollama (optional)
